# Battery Replacement — การเปลี่ยนแบตเตอรี่

## Summary

การเปลี่ยนแบตทั้งลูกคือ worst case ทางการเงินของการถือ EV — สำหรับ Cooper SE ความเสี่ยงนี้ต่ำกว่ารถแบตใหญ่เพราะ pack เล็ก (32.6 kWh) และโครงสร้างเป็นโมดูล (ซ่อมรายโมดูลได้ในทางเทคนิค) แต่ราคาศูนย์ในไทยยังเป็นคำถามใหญ่ที่ต้องหาคำตอบให้ได้ก่อนตัดสินใจซื้อรถหมดวอร์รันตี้

## Key Points

- โครงสร้าง 12 โมดูล → ในทางเทคนิค **เปลี่ยนรายโมดูลได้** ไม่ต้องทั้งลูกเสมอไป (ขึ้นกับนโยบายศูนย์)
- ราคาอ้างอิงต่างประเทศ (ทั้ง pack, รวมค่าแรง): หลักหลายแสนบาท — ตัวเลขไทยทางการ **ยังไม่มีข้อมูล ต้องสอบถามศูนย์**
- ทางเลือกนอกศูนย์ (กำลังโตในไทย): อู่ EV อิสระซ่อมระดับโมดูล/เซลล์ — ถูกกว่ามากแต่สละความเป็นมาตรฐานศูนย์
- สถิติสำคัญ: เคสต้องเปลี่ยนแบตทั้งลูกของตระกูล i3/SE เกิดน้อยมากเมื่อเทียบจำนวนรถ — ความเสี่ยงจริงคือ "กลัวเกินเหตุ" มากกว่าเหตุการณ์จริง
- กลยุทธ์ลดความเสี่ยงตอนซื้อ:
  1. เลือกคันที่วอร์รันตี้แบตเหลือนาน → [[03 Battery/Warranty]]
  2. ตรวจ SOH ก่อนซื้อ → [[03 Battery/Battery SOH]]
  3. ตรวจใต้ท้อง (ความเสียหายกายภาพน่ากลัวกว่าการเสื่อม)
