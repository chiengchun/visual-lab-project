# Recall — การเรียกคืนและ Technical Campaign

## Summary

Cooper SE มี recall / technical campaign จำนวนไม่มากตลอดอายุรุ่น ส่วนใหญ่เป็นการอัปเดตซอฟต์แวร์ระบบไฟฟ้าแรงสูงและตรวจสอบชิ้นส่วน สิ่งสำคัญสำหรับผู้ซื้อมือสอง: **เช็ค recall คงค้างจาก VIN ที่ศูนย์ก่อนซื้อทุกครั้ง** — งาน recall ทำฟรีเสมอไม่ว่ารถหมดวอร์รันตี้หรือไม่

## Key Points

- Recall ทำฟรี 100% ที่ศูนย์ ตลอดอายุรถ — รถที่มี recall ค้างคือรถที่เจ้าของเดิมละเลย (สัญญาณเรื่องการดูแลโดยรวม)
- ช่องทางตรวจ:
  1. ศูนย์ MINI ตรวจจาก VIN (แม่นสุด ครอบคลุม campaign ของไทย)
  2. เว็บ recall ของ BMW/MINI ตลาดต่างประเทศ (NHTSA สำหรับสหรัฐ) — ใช้ดูแนวโน้ม แต่รายการอาจต่างจากรถไทย
- รายการที่เคยเป็นข่าวในตลาดโลก *(ต้องยืนยันหมายเลข campaign และผลต่อรถไทยทีละรายการ)*:
  - ตรวจสอบ/อัปเดตซอฟต์แวร์ระบบชาร์จ–อิเล็กทรอนิกส์กำลัง (EME/KLE) ในรถล็อตแรก ๆ
  - Campaign ซอฟต์แวร์ BMS
  - Recall ทั่วไปของตระกูล F56 ที่ครอบคลุม SE ด้วย (เช่น ระบบกล้อง/ชิ้นส่วนย่อยตามล็อต)

> [!warning] หน้านี้ยังเป็นโครง
> ห้ามอ้างอิงรายการข้างบนกับผู้ขายจนกว่าจะยืนยันหมายเลข recall จริงจากศูนย์/เอกสารทางการ — โยนผลตรวจ VIN ของรถที่ดูเข้า Inbox แล้วอัปเดตหน้านี้
