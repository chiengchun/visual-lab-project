# Negotiation Guide — คู่มือต่อรองราคา

## Summary

การต่อรอง Cooper SE มือสองมีแต้มต่อฝั่งผู้ซื้อ: ตลาด EV มือสองไทยเป็นตลาดของผู้ซื้อ (ราคาโดนกดจาก EV จีนและเจนใหม่) และรถรุ่นนี้มีจุดเทคนิคที่ใช้ต่อรองได้เป็นรูปธรรม โดยเฉพาะ SOH และวอร์รันตี้แบตคงเหลือ หลักการสำคัญ: **ต่อรองด้วยข้อมูล ไม่ใช่อารมณ์** และทุกข้ออ้างต้องมีเอกสาร/หลักฐานประกอบ

## Key Points

### แต้มต่อฝั่งผู้ซื้อ (ใช้ได้เสมอ)

- ตลาด EV มือสองไทยมี supply มากกว่า demand — ผู้ขายรอนาน
- Cooper SE เป็นรถเฉพาะกลุ่ม ผู้ซื้อจริงมีน้อย ผู้ขายรู้ดี
- เจนใหม่ (J01) ราคาป้ายไม่แพงมาก กดเพดานราคามือสอง F56

### ข้อต่อรองเชิงเทคนิค (ต้องมีหลักฐาน)

| ประเด็น | ใช้ต่อรองอย่างไร |
| --- | --- |
| SOH ต่ำกว่า 90% | อ้างต้นทุนความเสี่ยงแบต ขอส่วนลดตามสัดส่วน |
| วอร์รันตี้แบตเหลือน้อย (<2 ปี) | เทียบกับคันที่ปีใหม่กว่า ราคาต้องห่างชัดเจน |
| ไม่มีประวัติศูนย์ | หักราคาความเสี่ยง หรือขอให้เข้าศูนย์ตรวจก่อนโอน |
| ยางหมดอายุ/เบรกสนิม | หักราคาตามค่าใช้จ่ายจริง → [[04 Ownership/Tires]] [[04 Ownership/Brake]] |
| Recall คงค้าง | ให้ผู้ขายจัดการก่อนโอน หรือหักราคา |
| ไม่มี wallbox/สายชาร์จติดรถ | สาย Mode 3 + wallbox มีต้นทุนจริง หักได้ |

### ลำดับการเจรจา

1. ทำการบ้านราคาก่อนคุย → [[02 Buying Guide/Price Guide]] + [[07 Market/Cars Watchlist]] (มีคันเทียบอย่างน้อย 3 คัน)
2. เปิดเจรจาต่ำกว่าราคาเป้าหมาย ~5–8% (ไม่ต่ำจนเสียเครดิต)
3. ยื่นเงื่อนไขแลกเปลี่ยนแทนการกดราคาอย่างเดียว เช่น ราคานี้ + ผู้ขายจ่ายค่าตรวจศูนย์ / แถมสายชาร์จ / จัดการ recall
4. พร้อมเดินออกเสมอ — ตลาดนี้มีรถใหม่เข้ามาเรื่อย ๆ

> [!tip] ประโยคที่ใช้ได้จริง
> "ผมเทียบมา 3 คันแล้ว คันนี้แพงกว่าค่าเฉลี่ยอยู่ X หมื่น ถ้าลงมาที่ ___ พร้อมผลตรวจ SOH ผมโอนเลย"
