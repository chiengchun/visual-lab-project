# Cooper SE vs Cooper S — ไฟฟ้าปะทะเบนซินในตัวถังเดียวกัน

## Summary

คู่เปรียบเทียบที่ตรงที่สุด: ตัวถัง F56 เดียวกัน ราคามือสองใกล้กัน ต่างกันที่ขุมพลัง — SE ให้ torque ทันทีและค่าใช้จ่ายต่อกม.ต่ำกว่า ~70% ส่วน S (2.0 เทอร์โบ 192 hp) ให้เสียง อารมณ์ และอิสระเรื่องระยะทาง คำตอบขึ้นกับรูปแบบการใช้งานล้วน ๆ

## ตารางเปรียบเทียบ

| หัวข้อ | Cooper SE | Cooper S (F56 เบนซิน) |
| --- | --- | --- |
| ขุมพลัง | มอเตอร์ 184 hp / 270 Nm | 2.0 เทอร์โบ 192 hp / 280 Nm |
| 0–100 | 7.3 วิ | ~6.8 วิ |
| อารมณ์ | เงียบ พุ่งทันที จุดศูนย์ถ่วงต่ำกว่า | เสียงเครื่อง/ท่อ อารมณ์สันดาป |
| ค่าเชื้อเพลิง/ไฟ | ~0.4–0.9 บาท/กม. | ~2.5–3.5 บาท/กม. |
| ค่าบำรุงรักษา/ปี | ต่ำ | สูงกว่าชัดเจน (น้ำมันเครื่อง หัวเทียน ระบบเทอร์โบ) |
| ระยะทาง/ความยืดหยุ่น | ~180 กม./ชาร์จ ต้องวางแผน | เติมน้ำมัน 3 นาที ไปได้ทุกที่ |
| ความเสี่ยงระยะยาว | แบต (มีวอร์รันตี้ 8 ปีคุม) | เครื่อง/เกียร์ตามไมล์ (ไม่มีตาข่าย) |
| ภาษีประจำปี | ถูกกว่า (EV) | ปกติ |

## จุดตัดสิน (Decision Rules)

1. **วิ่งวันละ <120 กม. + มีที่ชาร์จบ้าน** → SE คุ้มกว่าทางการเงินแบบไม่ต้องคิด
2. **เดินทางไกลบ่อย / ไม่มีที่ชาร์จ** → S ตอบโจทย์กว่า
3. **ถือยาว 5+ ปี** → SE: ความเสี่ยงแบตมีวอร์รันตี้คุมถึงปี 2029–2032 / S: ความเสี่ยงเครื่องยนต์โตตามไมล์แบบไม่มีเพดาน
4. **ซื้อเพื่อขาย 2–3 ปี** → ต้องดู [[07 Market/Market Analysis]] — ค่าเสื่อม EV ยังผันผวนกว่า
