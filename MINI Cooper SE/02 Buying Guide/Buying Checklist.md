# Buying Checklist — รายการตรวจก่อนซื้อ Cooper SE มือสอง

## Summary

เช็คลิสต์สำหรับใช้จริงหน้างานเมื่อไปดูรถ แบ่งเป็น เอกสาร → แบตเตอรี่ → ตัวรถ → ทดลองขับ → ราคา พิมพ์หรือเปิดหน้านี้บนมือถือแล้วติ๊กตามได้เลย

## 1️⃣ เอกสาร

- [ ] เล่มทะเบียนตรงกับ VIN บนตัวถัง → [[02 Buying Guide/VIN Decoder]]
- [ ] วันจดทะเบียนครั้งแรก (ใช้คำนวณวอร์รันตี้แบต 8 ปี) → [[03 Battery/Warranty]]
- [ ] ประวัติเซอร์วิสศูนย์ MINI ครบ (ขอ statement จากศูนย์ได้)
- [ ] MSI / BSI เหลือหรือไม่ ถึงเมื่อไร
- [ ] ตรวจภาระผูกพัน (ไฟแนนซ์ค้าง/ติดจำนำ)
- [ ] ประวัติอุบัติเหตุ/เคลมประกัน (ขอเช็คจากบริษัทประกันเดิม)

## 2️⃣ แบตเตอรี่ (สำคัญที่สุด)

- [ ] **ขอ Battery SOH report จากศูนย์ MINI** — ตัวเลขต่ำกว่า ~85% ต้องต่อรองหนักหรือถอย → [[03 Battery/Battery SOH]]
- [ ] ทดสอบชาร์จ AC ได้จริง (สายติดรถ + wallbox ถ้ามี)
- [ ] ทดสอบชาร์จ DC ได้จริง (แวะตู้ DC ระหว่างทดลองขับถ้าเป็นไปได้)
- [ ] ฝาชาร์จล็อค/ปลดล็อคปกติ (จุดเสียที่พบบ่อย) → [[05 Problems/Common Issues]]
- [ ] ดูระยะทางคงเหลือที่ 100% เทียบกับที่ควรเป็น (~180–230 กม. บนหน้าจอ)

## 3️⃣ ตัวรถ

- [ ] ใต้ท้อง: แผ่นปิดแบตไม่มีรอยกระแทก/บุบ (สำคัญมาก — กระแทกแบต = เสี่ยงหมดวอร์รันตี้)
- [ ] สีรอบคัน เช็คซ่อมสี/เปลี่ยนชิ้น
- [ ] ยาง: ปี, ความลึกดอก, ขนาดตรงสเปก → [[04 Ownership/Tires]]
- [ ] เบรก: สนิมที่จาน (โรคเบรกไม่ค่อยถูกใช้เพราะ regen) → [[04 Ownership/Brake]]
- [ ] แอร์/heat pump เย็นเร็ว ไม่มีเสียงผิดปกติ
- [ ] ไฟท้าย Union Jack ไม่มีไอน้ำเกาะ (โรคประจำรุ่น)
- [ ] จอกลาง + Apple CarPlay ทำงานปกติ ไม่รีบูตเอง → [[05 Problems/Known Bugs]]

## 4️⃣ ทดลองขับ

- [ ] เร่ง 0–100: ต้องพุ่งต่อเนื่อง ไม่มีอาการสะดุด/ตัดกำลัง
- [ ] Regen 2 ระดับทำงานทั้งคู่ (สวิตช์ toggle ข้างเกียร์)
- [ ] โหมด Sport / MID / GREEN / GREEN+ สลับได้ครบ
- [ ] ฟังเสียงช่วงล่าง (บูช/ลูกหมากตามอายุ)
- [ ] ไม่มีไฟเตือน drivetrain/แบตค้างบนหน้าปัด

## 5️⃣ ราคาและตัดสินใจ

- [ ] เทียบราคากับ [[07 Market/Price Guide|Price Guide]] และ [[07 Market/Cars Watchlist]]
- [ ] ประเมิน Good Deal / Fair / Overpriced พร้อมเหตุผล
- [ ] บันทึกคันนี้เข้า [[07 Market/Cars Watchlist]] ทุกครั้งไม่ว่าซื้อหรือไม่

> [!warning] Deal breakers — เจอข้อใดข้อหนึ่ง = ถอย
> SOH ต่ำผิดปกติโดยไม่ลดราคา · แผ่นใต้แบตมีรอยกระแทกหนัก · ประวัติน้ำท่วม · ชาร์จ DC ไม่เข้า · เอกสารไม่ตรง VIN
