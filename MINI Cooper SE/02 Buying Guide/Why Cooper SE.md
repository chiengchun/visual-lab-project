# Why Cooper SE — เหตุผลที่เลือก (และไม่เลือก)

## Summary

Cooper SE มือสองคือหนึ่งใน EV ที่ "สนุกต่อบาท" ที่สุดในตลาด: ขับสนุกแบบ go-kart, คุณภาพประกอบระดับ BMW Group, ราคามือสองถูกกดลงแรงจากระยะทางต่อชาร์จที่สั้นและการมาของเจนใหม่ เหมาะกับการใช้งานในเมืองเป็นหลัก ไม่เหมาะเป็นรถคันเดียวของบ้านที่ต้องเดินทางไกลบ่อย

## Key Points

### เหตุผลที่ควรซื้อ

- **ขับสนุกที่สุดในคลาส:** จุดศูนย์ถ่วงต่ำกว่ารุ่นเบนซิน, torque ทันที 270 Nm, พวงมาลัยคม
- **คุณภาพ Oxford:** ผลิตอังกฤษ มาตรฐาน BMW Group ต่างจาก EV ราคาเดียวกันหลายรุ่น
- **ค่าเสื่อมผ่านจุดชันมาแล้ว:** คนซื้อมือสองได้ประโยชน์จากค่าเสื่อมที่เจ้าของแรกรับไป
- **แบตเล็ก = เสี่ยงต่ำ:** แบต 32.6 kWh ต้นทุนเปลี่ยนต่ำกว่ารถแบตใหญ่ และสถิติ SOH ของแพลตฟอร์ม i3 อยู่ในเกณฑ์ดี → [[03 Battery/Battery Aging]]
- **ค่าบำรุงรักษาต่ำ:** ไม่มีน้ำมันเครื่อง เบรกสึกช้าเพราะ regen → [[04 Ownership/Maintenance]]

### เหตุผลที่ไม่ควรซื้อ

- **ระยะทางจริง ~160–185 กม./ชาร์จ** (เจ้าของ ตปท. รายงาน ~100–115 ไมล์ บนไฮเวย์; เมืองร้อนเปิดแอร์ได้ต่ำกว่า) — เดินทางข้ามจังหวัดต้องวางแผน → [[03 Battery/Charging]]
- **DC สูงสุด 50 kW** — ชาร์จเร็วสู้ EV ใหม่ไม่ได้
- **เบาะหลัง/ที่เก็บของเล็ก** (ท้าย 211 ลิตร) — ครอบครัวไม่สะดวก
- **อะไหล่/ศูนย์:** ต้องพึ่งศูนย์ MINI เป็นหลัก ค่าอะไหล่ระดับรถยุโรป → [[05 Problems/Repair Cost]]

## โปรไฟล์ผู้ใช้ที่เหมาะสม

| โปรไฟล์ | เหมาะไหม |
| --- | --- |
| รถคันที่สอง วิ่งในเมือง <100 กม./วัน มีที่ชาร์จที่บ้าน | ✅ เหมาะมาก |
| รถคันเดียว เดินทางต่างจังหวัดทุกเดือน | ⚠️ ต้องยอมรับการวางแผนชาร์จ |
| ไม่มีที่ชาร์จที่บ้าน/คอนโดไม่มีจุดชาร์จ | ❌ ไม่แนะนำ |
