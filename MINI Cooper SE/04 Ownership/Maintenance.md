# Maintenance — การบำรุงรักษา Cooper SE

## Summary

Cooper SE บำรุงรักษาถูกกว่ารถเบนซินอย่างมีนัยสำคัญ: ไม่มีน้ำมันเครื่อง หัวเทียน สายพาน ระบบไอเสีย รายการหลักเหลือเพียงตรวจเช็คตามรอบ (condition-based ตามที่รถแจ้ง) เบรก ยาง น้ำยาแอร์/coolant แบต 12V และไส้กรองแอร์ หน้านี้จะกลายเป็น service log จริงเมื่อมีใบเสร็จเข้ามา

## Key Points

- MINI ใช้ระบบ **CBS (Condition Based Service)** — รถแจ้งเองว่าถึงรอบอะไร ไม่ใช่ระยะตายตัว
- รายการตามรอบโดยทั่วไป:

| รายการ | รอบโดยประมาณ | หมายเหตุ |
| --- | --- | --- |
| ตรวจเช็คทั่วไป (vehicle check) | ~2 ปี | ตามที่ CBS แจ้ง |
| น้ำมันเบรก | ทุก 2 ปี | ไม่ขึ้นกับไมล์ |
| ไส้กรองแอร์ (microfilter) | ~1–2 ปี | ฝุ่นไทยควรถี่กว่า |
| Coolant ระบบแบต/มอเตอร์ | ตามกำหนด (ยาว) | ตรวจรั่วซึมทุกครั้งที่เข้าศูนย์ |
| แบต 12V | ตรวจทุกปี เปลี่ยน ~4–6 ปี | → [[04 Ownership/12V Battery]] |
| เบรก | ตรวจสนิม/ความหนา | สึกช้าเพราะ regen → [[04 Ownership/Brake]] |
| ยาง | ตามสภาพ/อายุ ≤6 ปี | → [[04 Ownership/Tires]] |

- **ไม่มี:** เปลี่ยนถ่ายน้ำมันเครื่อง, หัวเทียน, ไส้กรองน้ำมัน, สายพาน — งบต่อปีจึงต่ำ
- ค่าใช้จ่ายเฉลี่ยต่อปี (ประมาณการ ไม่รวมยาง): หลักพันถึงหมื่นต้น ๆ *(รอข้อมูลใบเสร็จจริงเพื่อยืนยัน)*
- MSI (MINI Service Inclusive) ครอบคลุมรายการตามรอบ — เช็คสิทธิ์คงเหลือก่อนซื้อรถ
