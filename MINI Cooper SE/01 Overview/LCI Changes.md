# LCI Changes — Facelift มีนาคม 2021

## Summary

LCI (Life Cycle Impulse) คือการ facelift ของตระกูล F56 ทั้งหมดรวมถึง Cooper SE ประกาศต้นปี 2021 เป็นการปรับภายนอก ภายใน และอุปกรณ์ โดย **ไม่แตะระบบขับเคลื่อนไฟฟ้าและแบตเตอรี่เลย**

## Key Points

### ภายนอก
- กันชนหน้าใหม่ ช่องรับลมออกแบบใหม่ ตัดไฟตัดหมอกออก (ฟังก์ชันรวมเข้าไฟหน้า LED)
- กระจังหน้าปิดเรียบแบบใหม่ ขอบล้อซุ้มโค้งสีตัวถัง (แล้วแต่สเปก)
- ไฟท้าย Union Jack (เริ่มมีมาก่อน LCI ตั้งแต่ปี 2018 ในตระกูล F56 — ไม่ใช่จุดแยก LCI)
- สีใหม่ เช่น Rooftop Grey, Zesty Yellow ล้อลายใหม่

### ภายใน
- พวงมาลัยดีไซน์ใหม่ (2 ก้าน มีแป้นทัชแบบใหม่)
- จอกลาง 8.8" เป็นมาตรฐาน พร้อม UI ปรับปรุง
- แผงแดชบอร์ดตกแต่งใหม่ ไฟ ambient ปรับปรุง

### อุปกรณ์
- Lane Departure Warning เพิ่มเป็นมาตรฐานในหลายตลาด
- Multitone Roof (หลังคาไล่เฉดสี) เป็น option ตามมา ~ปลาย 2021/2022

### สิ่งที่ไม่เปลี่ยน
- มอเตอร์ 135 kW / 270 Nm · แบตเตอรี่ 32.6 kWh · ระยะทาง WLTP · ระบบชาร์จ AC 11 kW / DC 50 kW

## วิธีแยกรถ Pre-LCI กับ LCI เร็ว ๆ

1. ดูกันชนหน้า: มีไฟตัดหมอกกลม = Pre-LCI, ปิดเรียบไม่มี = LCI
2. ดูพวงมาลัย: ก้านแบบเดิม = Pre-LCI, ดีไซน์ใหม่ = LCI
3. เช็คเดือนผลิตจาก VIN / แผ่นป้ายที่เสา B → [[02 Buying Guide/VIN Decoder]]
