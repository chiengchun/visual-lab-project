## Prompt 1 — กวาดตลาดมือสองไทย (ป้อน Price Guide + Watchlist)

```
ช่วยทำ deep research ประกาศขาย MINI Cooper SE (รุ่นไฟฟ้า F56, ปี 2020-2024) มือสองในประเทศไทยที่ยังประกาศขายอยู่ตอนนี้ จากทุกแหล่ง: one2car, Kaidee Auto, taladrod, Carsome, Roddonjai, กลุ่ม Facebook (MINI EV Thailand, MINI Thailand Club, ตลาดซื้อขาย MINI)

ต้องการผลลัพธ์เป็นตาราง Markdown คอลัมน์: ปีจดทะเบียน | เลขไมล์ | สี | ราคาตั้ง | จังหวัด | ผู้ขาย (เต็นท์/บุคคล) | มีข้อมูล SOH หรือวอร์รันตี้เหลือไหม | URL | วันที่ลงประกาศ

ขอทุกคันที่หาเจอ (เป้าหมาย 10+ คัน) พร้อมสรุปท้ายตาราง: ช่วงราคาแยกตามปีรถ, ราคากลาง, จำนวน supply ทั้งตลาด และข้อสังเกตว่าคันไหนดูน่าสนใจ/ผิดปกติ ทุกรายการต้องมีลิงก์จริงที่เปิดได้
```

## Prompt 2 — ราคาและสเปกทางการไทย (ป้อน Model History + Price Guide)

```
ช่วย research ข้อมูลทางการของ MINI Cooper SE (F56 ไฟฟ้า) ในประเทศไทย:
1. วันเปิดตัวในไทยและราคาเปิดตัวทางการ (ล้านบาท) พร้อมแหล่งข่าว
2. การปรับราคา/ปรับสเปกแต่ละปีจนถึงปีสุดท้ายที่ขาย (ขอ timeline)
3. สเปกไทยละเอียด: trim ที่ขาย, option มาตรฐาน (heat pump เป็นมาตรฐานไหม?), ขนาดล้อ/ยาง, รองรับชาร์จ AC กี่ kW (1 เฟส/3 เฟส)
4. เงื่อนไขวอร์รันตี้ไทยทางการ: ตัวรถกี่ปี, แบตแรงดันสูงกี่ปี/กี่กม., เกณฑ์เคลมแบต (SOH ต่ำกว่ากี่ % ถึงเคลมได้), MSI/BSI มีแพ็กเกจอะไร
แหล่งที่ควรดู: ข่าว launch จาก Headlightmag, Autolifethailand, Motortrivia, เว็บ MINI Thailand, โบรชัวร์ ทุกข้อต้องแนบลิงก์อ้างอิง แยกให้ชัดว่าข้อไหนยืนยันจากแหล่งทางการ ข้อไหนเป็นข้อมูลมือสอง
```

## Prompt 3 — Recall และ Technical Campaign (ป้อน 05 Problems/Recall)

```
ช่วย research รายการ recall และ technical/service campaign ทั้งหมดของ MINI Cooper SE (F56 BEV, ปีผลิต 2019-2024) จากฐานข้อมูลทางการ: NHTSA (สหรัฐ), UK DVSA, KBA (เยอรมนี), ประกาศ recall ในไทย (สมอ./กรมขนส่ง/ข่าว)

ต้องการตาราง: หมายเลข campaign/recall | ปีประกาศ | ชิ้นส่วน/ระบบที่เกี่ยวข้อง | อาการ/ความเสี่ยง | วิธีแก้ | ช่วง VIN หรือช่วงเดือนผลิตที่กระทบ | ลิงก์อ้างอิง

เน้นพิเศษ: recall ที่เกี่ยวกับแบตเตอรี่แรงดันสูง, ระบบชาร์จ (KLE/EME), ซอฟต์แวร์ BMS และระบุว่ารายการไหนน่าจะกระทบรถที่ขายในไทย (สเปกยุโรป/UK)
```

## Prompt 4 — ปัญหาจริงและค่าซ่อมจริงในไทย (ป้อน Common Issues + Repair Cost)

```
ช่วย research ปัญหาที่เจ้าของ MINI Cooper SE (รุ่นไฟฟ้า) ในไทยเจอจริง และค่าซ่อมจริงที่มีการรายงาน จาก: Pantip, กลุ่ม Facebook เจ้าของ MINI/MINI EV Thailand, YouTube รีวิว long-term ของคนไทย

ต้องการ:
1. รายการปัญหาที่ถูกพูดถึง เรียงตามความถี่ พร้อมลิงก์กระทู้/โพสต์ต้นทาง
2. ตัวเลขค่าซ่อม/ค่าอะไหล่จริงทุกตัวที่หาเจอ (เช่น เปลี่ยนแบต 12V, ซ่อมระบบชาร์จ, เช็คระยะ, เปลี่ยนยาง) ระบุ ศูนย์หรืออู่ + ปีของข้อมูล + ลิงก์
3. เคสเคลมวอร์รันตี้แบตในไทย (ถ้ามี) จบอย่างไร
ห้ามประมาณตัวเลขเอง — เอาเฉพาะตัวเลขที่มีคนรายงานจริงพร้อมที่มา
```

## Prompt 5 — ข้อมูลการเสื่อมแบตจริงทั่วโลก (ป้อน Battery SOH + Battery Aging)

```
ช่วย research ข้อมูล battery degradation / SOH จริงของ MINI Cooper SE (F56, แบต 32.6 kWh) จากเจ้าของรถทั่วโลก: Reddit (r/MiniCooperSE, r/electricvehicles), Speak EV forum, MINI forums, บทความ long-term test ที่วัดความจุจริง

ต้องการตาราง: อายุรถ (ปี) | เลขไมล์ | SOH หรือความจุที่วัดได้ | วิธีวัด (ศูนย์/Bimmerlink/อื่น) | พฤติกรรมชาร์จของเจ้าของ (AC/DC, ชาร์จถึงกี่ %) | ลิงก์

เป้าหมาย 15+ data point แล้วสรุป: ค่าเฉลี่ย SOH ต่ออายุรถ, เคสที่เสื่อมเร็วผิดปกติเกิดจากอะไร, และเทียบกับสถิติของ BMW i3 (แบตตระกูลเดียวกัน)
```
