# VIN Decoder — อ่านรหัสตัวถัง Cooper SE

## Summary

VIN (Vehicle Identification Number) 17 หลักบอกโรงงานผลิต รุ่น และลำดับการผลิต ใช้ยืนยันว่ารถตรงกับเอกสาร ตรวจเดือน/ปีผลิตจริง (สำคัญต่อการแยก Pre-LCI/LCI และคำนวณอายุแบต) และใช้เช็ค recall/option ที่ติดรถจากโรงงาน

## Key Points

- Cooper SE (F56 BEV) ใช้รหัสรุ่นภายใน **F56 BEV** — VIN ขึ้นต้น `WMW` (MINI, ผลิตโดย BMW Group)
- ตำแหน่ง VIN บนรถ: มุมล่างกระจกหน้าฝั่งคนขับ, เสาประตู B ฝั่งคนขับ, เล่มทะเบียน
- เดือน/ปีผลิตจริง: ดูจากแผ่นป้ายที่เสา B หรือถอดรหัสผ่านเว็บ decoder
- นำ VIN ไปเช็คได้:
  - **Option list จากโรงงาน** ผ่านเว็บ VIN decoder ของ BMW/MINI (เช่น bimmer.work, mdecoder) — เห็นว่ารถคันนั้นมี option อะไรติดมาบ้าง เทียบกับที่ผู้ขายอ้าง
  - **Recall คงค้าง** ผ่านศูนย์ MINI → [[05 Problems/Recall]]
  - **ประวัติเซอร์วิส** ขอจากศูนย์ MINI ด้วย VIN

## วิธีใช้งานจริงตอนดูรถ

1. ถ่ายรูป VIN จากตัวรถ (ไม่ใช่จากเอกสาร)
2. เทียบกับเล่มทะเบียน — ต้องตรงทุกหลัก
3. ใส่ใน VIN decoder → ได้เดือนผลิต + option list
4. เดือนผลิตก่อน ~มี.ค. 2021 = Pre-LCI, หลัง = LCI → [[01 Overview/LCI Changes]]
5. เอา option list เทียบกับตัวรถจริง (เช็ครถถูกเปลี่ยนชิ้นส่วน/แต่งเพิ่ม)

> [!tip]
> ขอ VIN จากผู้ขายก่อนไปดูรถ แล้ว decode ล่วงหน้า จะรู้ทั้งสเปกจริง เดือนผลิต และคำถามที่ต้องถามก่อนเสียเวลาเดินทาง
