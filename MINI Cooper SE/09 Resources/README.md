# 🗄️ Resources — คลังเอกสารต้นฉบับ

เก็บไฟล์ต้นฉบับที่ผ่านการสกัดความรู้แล้ว แยกตามประเภท:

| โฟลเดอร์ | เก็บอะไร |
| --- | --- |
| `Manuals/` | คู่มือรถ, owner's manual, warranty booklet |
| `Brochures/` | โบรชัวร์/spec sheet แต่ละปี |
| `Service Bulletins/` | ใบเสร็จ, ใบเสนอราคา, TSB, ผลตรวจศูนย์ |
| `Photos/` | รูปรถ, รูปเปรียบเทียบ Pre-LCI/LCI, รูปจุดตรวจ |
| `Videos/` | ไฟล์วิดีโอ/บันทึกที่ดาวน์โหลดเก็บ |

กติกา: ไฟล์ทุกไฟล์ในนี้ต้องถูกอ้างถึง (Reference) จากไฟล์ความรู้อย่างน้อย 1 หน้า — ถ้าไม่มีหน้าไหนอ้าง แปลว่ายังไม่ได้สกัดความรู้ ให้กลับไปทำ workflow ใน [[CLAUDE|Project Spec]]
