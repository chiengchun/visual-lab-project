# Known Bugs — บั๊กซอฟต์แวร์ที่รู้จักกันดี

## Summary

บั๊กของ Cooper SE เกือบทั้งหมดอยู่ฝั่ง infotainment และแอป ไม่กระทบการขับขี่ ส่วนใหญ่ทุเลาหรือหายเมื่ออัปเดตซอฟต์แวร์เป็นเวอร์ชันล่าสุดที่ศูนย์ รถมือสองที่ขาดการอัปเดตนานจะเจอบั๊กเหล่านี้ครบชุด — อย่าเพิ่งตัดสินว่ารถเสีย

## Key Points

| บั๊ก | อาการ | ทางแก้ |
| --- | --- | --- |
| จอกลางรีบูตเอง | จอดับแล้วกลับมาใหม่ระหว่างขับ | อัปเดตซอฟต์แวร์ / เช็คแบต 12V |
| CarPlay หลุด/ต่อไม่ติด | ต่อแล้วหลุดเป็นพัก ๆ | อัปเดต + เปลี่ยนสาย/ลืมอุปกรณ์แล้วจับคู่ใหม่ |
| ระยะทางคงเหลือแกว่ง | ตัวเลข GOM กระโดดขึ้นลงแรง | พฤติกรรมปกติของ GOM — ไม่ใช่บั๊กแท้ ให้ดู % แบตแทน |
| แอป MINI ไม่อัปเดตสถานะ | สถานะชาร์จ/ตำแหน่งค้าง | logout-login, รอ server, ตรวจ ConnectedDrive |
| ตั้งเวลาชาร์จไม่ทำงานบางครั้ง | รถไม่เริ่มชาร์จตามเวลา | ตั้งค่าใหม่หลังอัปเดต / ใช้ตั้งเวลาฝั่ง wallbox แทน |
| เข็มไมล์/จอเพี้ยนชั่วคราว | กราฟิกค้างเสี้ยววินาที | อัปเดตซอฟต์แวร์ |

- **หลักวินิจฉัยลำดับแรกเสมอ:** (1) แบต 12V ดีไหม → (2) ซอฟต์แวร์ล่าสุดหรือยัง → (3) ค่อยสงสัยฮาร์ดแวร์
- บั๊กเหล่านี้ **ไม่ใช่เหตุถอยรถ** แต่ใช้เป็นข้อต่อรองย่อยได้ถ้าผู้ขายไม่เคยอัปเดต
