# Repair Cost — ฐานข้อมูลค่าซ่อมจริง

## Summary

ฐานข้อมูลราคาค่าซ่อม/ค่าอะไหล่จริงของ Cooper SE ในไทย เก็บจากใบเสร็จ ใบเสนอราคา และรายงานจากเจ้าของรถเท่านั้น — ไม่บันทึกตัวเลขลอย ๆ ใช้ประเมินงบสำรองหลังซื้อและใช้ต่อรองราคารถที่มีรายการต้องซ่อม

## Key Points

- แหล่งข้อมูลที่รับ: ใบเสร็จศูนย์/อู่ (ดีสุด), ใบเสนอราคา, โพสต์เจ้าของรถที่ระบุตัวเลขชัด
- ทุกแถวต้องมี: วันที่ + แหล่ง + ราคา — ไม่ครบไม่ลงตาราง
- งบสำรองแนะนำหลังซื้อรถหมดวอร์รันตี้: *(จะคำนวณได้เมื่อตารางมีข้อมูลพอ)*
