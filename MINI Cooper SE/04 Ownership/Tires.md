# Tires — ยางสำหรับ Cooper SE

## Summary

Cooper SE ใช้ยางขนาดเดียวกับตระกูล F56 ทั่วไป (16"/17") แต่พฤติกรรม EV — torque ทันที + น้ำหนักมากกว่ารุ่นเบนซิน ~150 กก. — ทำให้ยางหน้าสึกเร็วกว่าที่คาด ยางเป็นค่าใช้จ่ายหมุนเวียนก้อนใหญ่ที่สุดของรถรุ่นนี้ และเป็นข้อต่อรองราคาที่จับต้องได้ตอนซื้อมือสอง

## Key Points

- **ขนาดมาตรฐาน:** 195/55 R16 หรือ 205/45 R17 (แล้วแต่ล้อจากโรงงาน) *(ยืนยันสเปกไทย)*
- น้ำหนักรถ ~1,365 กก. + torque 270 Nm ลงล้อหน้า → **ยางหน้าสึกเร็ว** ควรสลับยางทุก ~10,000 กม.
- เลือกยางสำหรับ EV ได้เปรียบ: rolling resistance ต่ำ = ระยะทางเพิ่ม, เสียงเงียบสำคัญเพราะไม่มีเสียงเครื่องกลบ
- แรงดันลมตามฝาถัง — เช็คสม่ำเสมอ ลมอ่อนกินไฟชัดเจน
- อายุยางไม่ควรเกิน 6 ปีจากปีผลิต (ดู DOT) แม้ดอกเหลือ
