# Accessories — อุปกรณ์เสริมที่ควรมี

## Summary

อุปกรณ์เสริมที่มีผลต่อการใช้งานจริงของ Cooper SE เรียงตามความจำเป็น: wallbox และสายชาร์จมาก่อนทุกอย่าง ที่เหลือเป็นของตกแต่ง/อำนวยความสะดวก ราคาที่บันทึกไว้ให้ถือเป็นประมาณการจนกว่าจะมีใบเสร็จจริง

## Key Points

### จำเป็น (เกี่ยวกับการชาร์จ)

| รายการ | ประมาณราคา (บาท) | หมายเหตุ |
| --- | --- | --- |
| Wallbox AC (7.4–22 kW) + ติดตั้ง | 25,000–60,000 | รถรับสูงสุด 11 kW → ไม่จำเป็นต้องซื้อเกิน |
| ขอมิเตอร์ TOU / เพิ่มขนาดมิเตอร์ | ~700–หลักพัน + ค่าเดินสาย | คุ้มถ้าชาร์จกลางคืน → [[03 Battery/Charging]] |
| สายชาร์จ Mode 3 (Type 2, พกพา) | 8,000–15,000 | เช็คว่าติดรถมาไหมตอนซื้อ |
| สาย Mode 2 (ปลั๊กบ้าน ฉุกเฉิน) | ติดรถ | เช็คของแท้ครบชุด |

### ควรมี

- ฟิล์มกันความร้อนคุณภาพสูง (ลดภาระแอร์ = เพิ่มระยะทาง)
- ที่บังแดดกระจกหน้า (ถนอมแบตจากความร้อน → [[03 Battery/Battery Aging]])
- OBD adapter + Bimmerlink (ตรวจสุขภาพรถเอง → [[03 Battery/Battery SOH]])
- ยางปูพื้น/ถาดท้ายแบบ EV

### ของแต่ง (ตามใจ)

- ล้อแท้ลาย Corona Spoke/Power Spoke, ชุดแต่ง JCW look, side scuttle ลาย Electric
