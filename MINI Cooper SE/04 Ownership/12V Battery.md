# 12V Battery — แบตเตอรี่ 12 โวลต์

## Summary

เหมือน EV ทุกคัน Cooper SE ยังมีแบต 12V สำหรับระบบไฟฟ้าพื้นฐาน (ปลดล็อค, คอมพิวเตอร์, จอ) และเป็นสาเหตุอันดับต้นของอาการ "รถสตาร์ทไม่ติด/ขึ้นเตือนมั่ว" — แบตขับเคลื่อนไม่เกี่ยว อาการประหลาดหลายอย่างของรถรุ่นนี้จบที่การเปลี่ยนแบต 12V ลูกละไม่กี่พันบาท

## Key Points

- แบต 12V ถูกประจุจากแบตแรงดันสูงผ่าน DC-DC converter ขณะรถ ready/ชาร์จ
- **อายุใช้งานทั่วไป 4–6 ปี** — รถปี 2020–2021 ในตลาดมือสองตอนนี้มักถึงรอบเปลี่ยนแล้ว (ถามประวัติ!)
- อาการแบต 12V อ่อน: ไฟเตือนหลายรายการขึ้นพร้อมกันแบบไม่มีเหตุผล, จอ/ระบบรีบูต, ปลดล็อคช้า, รถไม่ยอม ready
- รถจอดนานหลายสัปดาห์ → แบต 12V หมดได้ (ระบบ standby ยังกินไฟ) — จัมพ์ได้ตามคู่มือ (ขั้วจัมพ์ในห้องเก็บของหน้า/ตามคู่มือ)
- สเปกแบต: AGM ขนาดเล็ก — เปลี่ยนแล้วควร register กับระบบรถ (ให้ศูนย์/อู่ที่มีเครื่องมือทำ)

## ตอนดูรถมือสอง

- [ ] ถามว่าเคยเปลี่ยนแบต 12V หรือยัง เมื่อไร
- [ ] สังเกตอาการตอนเปิดรถ: ระบบตื่นช้า/ไฟเตือนแปลก = สงสัยแบต 12V ก่อน
- [ ] รถที่จอดขายนาน ๆ ที่เต็นท์: แบต 12V มักโทรม ใช้เป็นข้อต่อรองย่อยได้
