# Software Update — การอัปเดตซอฟต์แวร์

## Summary

Cooper SE (F56) เป็นรถยุคก่อน OTA เต็มรูปแบบ — การอัปเดตสำคัญ (ระบบขับเคลื่อน, BMS, แก้ recall เชิงซอฟต์แวร์) ต้องทำที่ศูนย์ผ่านระบบ ISTA ส่วนแผนที่/ระบบ infotainment บางส่วนอัปเดตผ่าน USB หรือ ConnectedDrive ได้เอง สถานะซอฟต์แวร์ล่าสุดมีผลจริงต่ออาการบั๊กหลายอย่าง

## Key Points

- **3 ช่องทางอัปเดต:**
  1. **ศูนย์ (ISTA)** — เฟิร์มแวร์ทั้งคัน รวม BMS/EME/KLE และ technical campaign ต่าง ๆ
  2. **USB / ConnectedDrive** — แผนที่นำทาง และ software infotainment บางเวอร์ชัน
  3. **แอป MINI** — ฟีเจอร์ remote (สถานะแบต, precondition, ตำแหน่งรถ)
- บั๊กหลายรายการใน [[05 Problems/Known Bugs]] แก้ได้ด้วยการอัปเดตเป็นเวอร์ชันล่าสุด — รถมือสองที่ไม่เข้าศูนย์นานมักค้างเวอร์ชันเก่า
- ตอนซื้อรถ: ให้ศูนย์เช็คว่า **integration level / i-step** เป็นเวอร์ชันล่าสุดหรือไม่ และมี campaign ซอฟต์แวร์ค้างหรือเปล่า
- แอป MINI ต้องย้ายบัญชีเจ้าของ (remove เจ้าของเดิม → ผูกบัญชีใหม่) หลังโอนรถ

## Checklist หลังรับรถ

- [ ] ปลดบัญชี ConnectedDrive เจ้าของเดิม + ผูกบัญชีตัวเอง
- [ ] อัปเดตซอฟต์แวร์ทั้งคันที่ศูนย์ให้เป็นล่าสุด (ครั้งเดียวคุ้ม แก้บั๊กยกชุด)
- [ ] อัปเดตแผนที่ (ถ้ามีนำทาง)
- [ ] ทดสอบแอป MINI ครบทุกฟังก์ชัน
