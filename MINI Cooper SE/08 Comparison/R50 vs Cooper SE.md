# R50 vs Cooper SE — MINI คลาสสิกยุคใหม่ปะทะ MINI ไฟฟ้า

## Summary

เปรียบเทียบ MINI เจนแรกยุค BMW (R50, 2001–2006) กับ Cooper SE (F56 BEV) — สองขั้วของความเป็น MINI: R50 คือความดิบ เบา และกลไกล้วน ส่วน SE คือ go-kart feeling เวอร์ชันไร้เสียงพร้อม torque ทันที ทั้งคู่แชร์ DNA การขับที่คมแบบ MINI แต่ประสบการณ์และภาระการดูแลต่างกันคนละโลก

## ตารางเปรียบเทียบ

| หัวข้อ | R50 (Cooper) | Cooper SE (F56 BEV) |
| --- | --- | --- |
| ปีผลิต | 2001–2006 | 2019–2024 |
| ขุมพลัง | เบนซิน 1.6 (~115 hp) | มอเตอร์ไฟฟ้า 184 hp / 270 Nm |
| น้ำหนัก | ~1,150 กก. | ~1,365 กก. |
| 0–100 | ~9 วินาที | 7.3 วินาที |
| ความรู้สึกขับ | ดิบ เบา สื่อสารตรง | หนึบ หนักแน่น torque ทันที เงียบ |
| ค่าบำรุงรักษา | สูง (รถเก่า อะไหล่ยุโรป จุกจิก) | ต่ำ (EV, ของสึกหรอน้อย) |
| ความเสี่ยงหลัก | เครื่อง/เกียร์/ระบบเก่าตามอายุ 20+ ปี | สุขภาพแบต (จัดการได้ด้วย SOH + วอร์รันตี้) |
| ความคลาสสิก/สะสม | ✅ เริ่มเป็น modern classic | 🔶 ว่าที่ classic (EV Oxford รุ่นเดียว) |
| ใช้งานประจำวันในไทย | ⚠️ ต้องใจรัก | ✅ สบาย ค่าไฟถูก |

## มุมมองการตัดสินใจ

- **ถ้าเป้าหมายคือรถใช้ทุกวัน:** SE ชนะขาด — ค่าใช้จ่าย ความน่าเชื่อถือ ความสะดวก
- **ถ้าเป้าหมายคือความหลงใหล/งานอดิเรก:** R50 ให้ประสบการณ์กลไกที่ SE ให้ไม่ได้
- ทั้งสองคันไม่ใช่คู่แทนกัน — เป็นคำตอบของคำถามคนละข้อ การถือทั้งคู่ (ถ้ามี R50 อยู่แล้ว) คือส่วนผสมที่ลงตัว: SE วิ่งงานประจำวัน R50 เก็บไว้ขับวันหยุด
